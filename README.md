# java-racingcar-precourse

1. 입출력 구현
  - 입력 구현
  - 경주 상황 출력 구현
  - 최종 우승자 출력 구현

2. car 도메인 구현

3. 예외 처리
  - 이름이 6자 이상일 때
  - 이름이 공백일 때
  - 시도할 횟수가 0번일 때
  - 시도할 횟수에서 숫자 이외의 문자를 입력받았을 때 

4. Inputparser 구현
  - 입력 받은 문자열 이름 나누기
  - 예외 처리 확인 구현

5. racinggame 도메인 구현
  - 자동차 생성
  - 경주 1회 진행 로직 구현
  - 총 경주 진행 구현
  - 우승자 판별 구현

6. controller 구현
  - 입력 처리 구현
  - 게임 진행 구현
  - 출력 처리 구현
